Mi Primer Repositorio

Este es mi primer proyecto utilizando Git y GitHub. Estoy aprendiendo a crear repositorios, guardar versiones y organizar mis proyectos de desarrollo web.

Lo que aprendí sobre Git y GitHub

  • Repositorio: espacio donde se almacenan los archivos y el historial de un proyecto.
  • Commit: registro de los cambios realizados en un proyecto.
  • GitHub: plataforma que permite almacenar y compartir repositorios de forma remota.
