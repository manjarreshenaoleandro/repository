# Mi Primer Repositorio

Este proyecto fue creado para aprender a utilizar Git y GitHub.

## Descripción

Es una página web sencilla desarrollada con HTML y CSS como parte de una actividad académica.

## Archivos del proyecto

- `index.html`: contiene la estructura de la página web.
- `estilos.css`: contiene los estilos visuales.
- `README.md`: contiene información sobre el proyecto.

## Lo que aprendí

Durante esta actividad aprendí a:

- Crear un repositorio local.
- Registrar cambios mediante commits.
- Utilizar `git status`.
- Utilizar `git add`.
- Utilizar `git commit`.
- Consultar el historial con `git log --oneline`.
- Publicar un repositorio en GitHub.
